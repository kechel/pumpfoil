# vier Textseiten (Nerd-Analysen 1–3, Systemarchitektur) — in allen Sprachen unter /<code>/.
#
# WARUM HIER (fast) NICHTS MEHR GESPERRT IST (06.09.2026):
# Bis dahin standen alle App-Routen auf `Disallow`, weil sie Gästen nur die Landing-Page zeigen.
# Google meldete daraufhin „Indexiert, obwohl durch robots.txt-Datei blockiert" — und das ist
# kein Widerspruch, sondern die Folge: eine gesperrte Seite wird nicht gecrawlt, also sieht
# Google dort auch kein `noindex`. Kennt es die Adresse trotzdem aus einem Link (ein geteilter
# Session-Link genügt), landet sie ohne Inhalt im Index, und man wird sie so nicht wieder los.
#
# Deshalb umgekehrt: crawlen erlauben, und der Server liefert für genau diese Routen
# `X-Robots-Tag: noindex, follow` aus (s. `spa()` in server/app/main.py). Das ist der einzige
# Weg, der Seiten wirklich aus dem Index hält.
#
# Gesperrt bleibt nur, was für einen Crawler ohnehin sinnlos ist und Last erzeugt.
User-agent: *
Disallow: /api/
Allow: /

Sitemap: https://pumpfoil.org/sitemap.xml
